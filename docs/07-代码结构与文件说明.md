# 代码结构与文件说明

本文档说明交付包中每个目录和主要文件负责的问题。接手人员可先看“核心调用链”，再按文件清单定位代码。

## 1. 核心调用链

### 1.1 文档入库

```text
frontend/src/views/DocumentsView.vue
  -> backend/app/api/v1/documents.py
  -> backend/app/services/document_upload_service.py
  -> backend/app/services/task_queue_service.py
  -> backend/app/workers/document_worker.py
  -> backend/app/services/document_pipeline.py
  -> parse/chunk/embed/minio/postgres
```

### 1.2 RAG 问答

```text
frontend/src/views/ChatView.vue
  -> backend/app/api/v1/chat.py
  -> backend/app/services/chat_service.py
  -> backend/app/services/retrieval_service.py
  -> backend/app/services/model_service.py / rerank_service.py
  -> PostgreSQL pgvector + Redis cache
```

### 1.3 评估和反馈

```text
frontend/src/views/EvaluationView.vue / ChatView.vue
  -> backend/app/api/v1/evaluation.py / feedback.py
  -> retrieval_service.py / chat_service.py
  -> evaluation_* / answer_feedbacks tables
```

## 8. 代码阅读建议

1. 先读 `backend/app/main.py` 和 `backend/app/api/v1/router.py`，理解 API 如何挂载。
2. 再读 `backend/app/api/v1/documents.py`、`document_upload_service.py`、`document_pipeline.py`，理解文档入库。
3. 然后读 `chat.py`、`chat_service.py`、`retrieval_service.py`，理解问答和检索。
4. 数据库结构以 `backend/app/db/models.py` 和 `backend/sql/001_init.sql` 为准。
5. 前端先读 `router/index.ts`、`api/client.ts`、`components/AppShell.vue`，再读具体页面。
