# 配置清单

配置模板：

```text
.env.example
```

生产环境应复制为 `.env` 后修改，`.env` 不进入交付和仓库。

## 一、应用配置

| 变量 | 默认值 | 说明 | 生产建议 |
| --- | --- | --- | --- |
| `APP_NAME` | `Java Internal RAG Service` | 应用名称 | 可保持默认 |
| `INTERNAL_API_PREFIX` | `/internal/rag` | Java 内部接口前缀 | 与 Java 配置保持一致 |
| `RAG_SERVICE_TOKEN` | `change-me` | 内部服务 token，预留给部分内部接口 | 生产必须修改 |
| `APP_PUBLIC_BASE_URL` | 空 | 应用公网地址，用于生成代理链接 | 如需外部访问文件链接则配置 |
| `CORS_ORIGINS` | localhost 前端 | 跨域来源 | 生产限制为实际前端域名 |

## 二、鉴权配置

| 变量 | 默认值 | 说明 | 生产建议 |
| --- | --- | --- | --- |
| `SA_TOKEN_JWT_SECRET` | `change-me` | Java Sa-Token JWT 验签密钥 | 必须与 Java `sa-token.jwt-secret-key` 一致 |
| `SA_TOKEN_JWT_ALGORITHM` | `HS256` | JWT 算法 | 与 Java 一致 |
| `SA_TOKEN_CLOCK_SKEW_SECONDS` | `60` | token 过期宽限秒数 | 30-120 秒 |
| `JWT_SECRET_KEY` | `change-me` | 本地 admin JWT 密钥 | 生产必须修改 |
| `JWT_ALGORITHM` | `HS256` | 本地 admin JWT 算法 | 可保持默认 |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | `1440` | 本地 admin token 过期时间 | 按安全要求调整 |
| `ADMIN_USERNAME` | `admin` | 初始化管理员 | 生产修改 |
| `ADMIN_PASSWORD` | `admin123` | 初始化管理员密码 | 生产修改 |

## 三、数据库配置

| 变量 | 默认值 | 说明 | 生产建议 |
| --- | --- | --- | --- |
| `DATABASE_URL` | `postgresql+asyncpg://rag:rag@localhost:5432/rag` | PostgreSQL 异步连接串 | 指向生产库 |
| `DATABASE_POOL_SIZE` | `5` | 连接池大小 | 按并发调大 |
| `DATABASE_MAX_OVERFLOW` | `10` | 额外连接数 | 按数据库容量设置 |
| `DATABASE_POOL_TIMEOUT_SECONDS` | `30` | 获取连接超时 | 可保持默认 |
| `DATABASE_POOL_RECYCLE_SECONDS` | `1800` | 连接回收秒数 | 可保持默认 |

生产示例：

```text
DATABASE_URL=postgresql+asyncpg://postgres:<password>@host.docker.internal:5432/ruoyi-ai
```

## 四、Redis 配置

| 变量 | 默认值 | 说明 | 生产建议 |
| --- | --- | --- | --- |
| `REDIS_URL` | `redis://localhost:6379/0` | Redis 连接串 | 指向服务内 Redis |
| `BACKGROUND_TASK_QUEUE_KEY` | `rag:background_tasks` | 后台任务队列 key | backend 和 worker 必须一致 |
| `BACKGROUND_WORKER_CONCURRENCY` | `1` | worker 并发数 | 资源足够时可调大 |
| `BACKGROUND_WORKER_POLL_TIMEOUT_SECONDS` | `5` | worker 阻塞等待秒数 | 可保持默认 |

## 五、MinIO 配置

| 变量 | 默认值 | 说明 | 生产建议 |
| --- | --- | --- | --- |
| `MINIO_ENDPOINT` | `localhost:9000` | MinIO API 地址 | 容器内使用服务名或内网地址 |
| `MINIO_ACCESS_KEY` | `minioadmin` | Access Key | 生产使用专用账号 |
| `MINIO_SECRET_KEY` | `minioadmin` | Secret Key | 生产使用强密码 |
| `MINIO_SECURE` | `false` | 是否 HTTPS | 生产按实际情况 |
| `MINIO_PUBLIC_BASE_URL` | `http://localhost:9000` | 对外访问基础地址 | 文件引用需要可访问 |
| `MINIO_DOCUMENTS_BUCKET` | `rag-documents` | 原始文档桶 | 需提前创建或应用创建 |
| `MINIO_PARSED_BUCKET` | `rag-parsed` | 解析结果桶 | 需提前创建 |
| `MINIO_PREVIEW_BUCKET` | `rag-preview` | 图片预览桶 | 需提前创建 |

## 六、模型配置

| 变量 | 默认值 | 说明 | 生产建议 |
| --- | --- | --- | --- |
| `DEEPSEEK_API_KEY` | 空 | 聊天模型 API Key | 必填 |
| `CHAT_MODEL` | `deepseek-v4-flash` | 聊天模型名 | 与账号可用模型一致 |
| `MODEL_REQUEST_TIMEOUT_SECONDS` | `90` | 模型请求超时 | 60-120 |
| `MODEL_REQUEST_RETRIES` | `2` | 模型请求重试 | 1-2 |
| `MODEL_MAX_CONCURRENT_REQUESTS` | `20` | 模型最大并发 | 按限流调整 |
| `CHAT_MAX_QUESTION_CHARS` | `2000` | 问题最大长度 | 可保持默认 |
| `CHAT_MAX_CONCURRENT_REQUESTS` | `20` | 单实例聊天并发 | 按服务资源调整 |
| `CHAT_GLOBAL_MAX_CONCURRENT_REQUESTS` | `0` | 全局聊天并发，0 表示不限制 | 多实例时建议配置 |

代码中固定：

- DeepSeek base URL：`https://api.deepseek.com`

## 七、Embedding 配置

| 变量 | 默认值 | 说明 | 生产建议 |
| --- | --- | --- | --- |
| `EMBEDDING_API_KEY` | 空 | Embedding API Key | 必填 |
| `EMBEDDING_MODEL` | `text-embedding-v4` | Embedding 模型 | 与向量维度匹配 |
| `EMBEDDING_DIMENSION` | `1024` | 向量维度 | 改动需迁移数据库 |
| `EMBEDDING_BATCH_SIZE` | `10` | 批量大小 | 按 API 限制调整 |
| `EMBEDDING_MAX_CONCURRENT_REQUESTS` | `8` | 并发 | 按限流调整 |
| `EMBEDDING_CACHE_ENABLED` | `true` | 是否缓存 embedding | 建议开启 |
| `EMBEDDING_CACHE_TTL_SECONDS` | `604800` | 缓存 TTL | 默认 7 天 |

代码中固定：

- DashScope OpenAI compatible base URL：`https://dashscope.aliyuncs.com/compatible-mode/v1`

## 八、Rerank 配置

| 变量 | 默认值 | 说明 | 生产建议 |
| --- | --- | --- | --- |
| `RERANK_API_KEY` | 空 | Rerank API Key | 使用 rerank 时必填 |
| `RERANK_MODEL` | `qwen3-vl-rerank` | Rerank 模型 | 与账号可用模型一致 |
| `RERANK_ENABLED` | `true` | 是否开启 rerank | 建议开启 |
| `RERANK_MAX_CANDIDATES` | `10` | 最大候选数 | 按耗时调整 |
| `RERANK_REQUEST_TIMEOUT_SECONDS` | `30` | 超时 | 可保持默认 |
| `RERANK_REQUEST_RETRIES` | `1` | 重试次数 | 可保持默认 |
| `RERANK_MAX_CONCURRENT_REQUESTS` | `20` | 并发 | 按限流调整 |

代码中固定：

- DashScope rerank URL：`https://dashscope.aliyuncs.com/api/v1/services/rerank/text-rerank/text-rerank`

## 九、切片和召回配置

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `CHUNK_SIZE` | `800` | 普通文本切片大小 |
| `CHUNK_OVERLAP` | `120` | 切片重叠长度 |
| `TABLE_CHUNK_ROWS` | `50` | 表格切片行数 |
| `TABLE_FULL_INDEX_MAX_ROWS` | `500` | 大表完整索引行数上限 |
| `TABLE_SAMPLE_ROWS` | `50` | 大表采样行数 |
| `MAX_DOCUMENT_CHUNKS` | `300` | 单文档最大切片数 |
| `MAX_EMBEDDING_CHARS_PER_DOCUMENT` | `200000` | 单文档最大向量化字符数 |
| `VECTOR_TOP_K` | `30` | 向量召回候选数 |
| `KEYWORD_TOP_K` | `30` | 关键词召回候选数 |
| `QA_TOP_K` | `10` | QA 召回候选数 |
| `RERANK_TOP_K` | `5` | 最终重排返回数 |
| `SIMILARITY_THRESHOLD` | `0.35` | 相似度阈值 |
| `RERANK_THRESHOLD` | `0.45` | 重排阈值 |

| `RETRIEVAL_CACHE_ENABLED` | `true` | 检索缓存 |
| `RETRIEVAL_CACHE_TTL_SECONDS` | `1800` | 检索缓存 TTL |
| `ANSWER_CACHE_ENABLED` | `true` | 答案缓存 |
| `ANSWER_CACHE_TTL_SECONDS` | `3600` | 答案缓存 TTL |

## 十一、OCR 配置

| 变量 | 默认值 | 说明 | 生产建议 |
| --- | --- | --- | --- |
| `OCR_ENABLED` | `true` | 是否启用 OCR | CPU 资源不足可关 |
| `OCR_LANG` | `ch` | OCR 语言 | 中文场景保持 `ch` |
| `OCR_PDF_DPI` | `180` | PDF OCR 渲染 DPI | 150-220 |
| `OCR_MIN_CONFIDENCE` | `0.45` | 最小置信度 | 可保持默认 |
| `OCR_MAX_PAGES` | `80` | OCR 最大页数 | 防止大文档拖垮服务 |
| `OCR_USE_GPU` | `false` | 是否使用 GPU | 有 GPU 环境再开启 |

远程 compose 默认设置 `OCR_ENABLED=false`，用于降低服务器资源占用。如果生产需要扫描件识别，需要改为 true 并确认依赖和资源。
