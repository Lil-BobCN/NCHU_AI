# 接口与数据字典

## 1. 通用约定

Base URL：

```text
http://127.0.0.1:8010
```

业务接口统一前缀：

```text
/api/v1
```

认证头：

```http
Authorization: Bearer <access_token>
```

成功响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

## 4. 枚举值

文档状态：

```text
uploaded, parsing, parsed, chunking, chunked, embedding, indexed, failed, deleted
```

任务状态：

```text
pending, running, succeeded, failed, skipped, canceled
```

QA 状态：

```text
enabled, disabled, draft
```

消息角色：

```text
user, assistant, system
```

## 5. MinIO 路径

| Bucket | 用途 |
| --- | --- |
| `rag-documents` | 原始文档 |

| `rag-preview` | 预览文件 |

documents/{yyyy}/{mm}/{document_id}/{original_file_name}
