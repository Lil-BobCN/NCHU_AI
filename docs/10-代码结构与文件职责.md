# 代码结构与文件职责

整理日期：2026-07-10

本文面向项目接手人，说明交付目录中每个目录和主要文件负责什么。阅读建议：先看本文件建立代码地图，再按 `05-Java对接接口文档.md` 和 `02-部署运维文档.md` 联调部署。

## 根目录

| 路径 | 作用 |
| --- | --- |
| `README.md` | 项目入口说明，描述 Java 后台与 Python RAG 服务的边界、接口前缀、权限模型和文档阅读顺序。 |
| `.env.example` | 环境变量模板。真实 `.env` 不交付、不入库，需要上线时由运维或项目负责人提供。 |
| `.gitignore` | Git 忽略规则，避免提交 `.env`、缓存、虚拟环境、编译产物等文件。 |
| `backend/` | FastAPI 后端服务、RAG 核心逻辑、数据库模型、迁移脚本、测试和镜像构建文件。 |
| `deploy/` | Docker Compose 部署编排和远程部署辅助脚本。 |
| `docs/` | 本次交接文档。 |

## backend 目录

| 路径 | 作用 |
| --- | --- |
| `backend/app/` | 应用源码目录，包含 API、配置、数据库、服务层和 worker。 |
| `backend/alembic/` | Alembic 数据库迁移目录，用于生产或迭代环境结构升级。 |
| `backend/sql/001_init.sql` | 全新 PostgreSQL 初始化 SQL，创建扩展、表和索引。 |
| `backend/tests/` | 单元测试和接口契约测试。 |
| `backend/Dockerfile` | 完整镜像构建文件，安装 Python 依赖、LibreOffice、OCR 依赖和字体。适合全新服务器构建。 |
| `backend/Dockerfile.lite` | 轻量镜像构建文件，通常用于不需要 OCR 或完整解析能力的场景。 |
| `backend/Dockerfile.reuse` | 复用基础镜像的构建文件，依赖 `rag-school-backend:runtime-base`，构建速度快但要求服务器已有基础镜像。 |
| `backend/requirements.txt` | 完整 Python 依赖。 |
| `backend/requirements-lite.txt` | 轻量依赖清单。 |
| `backend/pyproject.toml` | 项目元信息和 Ruff 配置。 |
| `backend/alembic.ini` | Alembic 命令配置。 |

## backend/app 源码目录

| 路径 | 作用 |
| --- | --- |
| `app/main.py` | FastAPI 应用入口，挂载 `/api/v1` 普通接口和 `/internal/rag` Java 内部接口，配置 CORS 和生命周期清理。 |
| `app/init_admin.py` | 初始化本地管理员账号，主要用于本地管理接口或调试。 |
| `app/api/` | HTTP API 层，只负责路由、鉴权依赖、请求校验和响应封装。 |
| `app/core/` | 基础设施代码，包括配置、统一响应、JWT 工具、JSON 转换和并发控制。 |
| `app/db/` | 数据库模型和异步连接。 |
| `app/schemas/` | 通用响应 schema。 |
| `app/services/` | 业务服务层，包含文档处理、解析、召回、问答、缓存、对象存储、模型调用等核心逻辑。 |
| `app/workers/` | 后台任务消费者，从 Redis 队列取任务执行文档处理和评测。 |

## API 层文件职责

| 文件 | 处理的问题 |
| --- | --- |
| `app/api/__init__.py` | API 包标识文件。 |
| `app/api/deps.py` | FastAPI 依赖注入：解析 Java Sa-Token JWT、本地 admin token、内部服务 token，生成当前用户对象。 |
| `app/api/v1/__init__.py` | v1 API 包标识文件。 |
| `app/api/v1/router.py` | 普通 `/api/v1` 路由聚合器，统一挂载 health、auth、documents、chat、feedback 等子路由。 |
| `app/api/v1/health.py` | 普通健康检查和 readiness 检查。 |
| `app/api/v1/auth.py` | 本地管理员登录、获取当前用户信息。Java internal 接口不依赖这里登录。 |
| `app/api/v1/documents.py` | 普通文档管理接口：上传、列表、详情、删除、批量操作、重新解析、切片、向量化、导出、解析结果和切片查看。 |
| `app/api/v1/jobs.py` | 查询文档任务进度和某文档下的任务列表。 |
| `app/api/v1/chat.py` | 普通问答接口，支持流式问答、非流式问答和撤回一轮消息。 |
| `app/api/v1/conversations.py` | 普通会话管理：创建、列表、消息、改名、删除。 |
| `app/api/v1/retrieval.py` | 检索调试接口和检索日志查询，用于排查召回结果。 |
| `app/api/v1/qa_pairs.py` | QA Pair 管理：查询、新增、修改、删除、启停。 |
| `app/api/v1/settings.py` | RAG 参数查询和更新接口。 |
| `app/api/v1/feedback.py` | 回答反馈接口，记录错误类型、说明、引用快照和处理状态。 |
| `app/api/v1/evaluation.py` | RAG 评测用例、评测运行和评测结果查询。 |
| `app/api/v1/files.py` | 文件代理下载接口，统一从 MinIO 读取并返回文件。 |
| `app/api/v1/internal.py` | Java 后台专用接口，前缀为 `/internal/rag`。处理文档接入、任务查询、会话、问答、权限范围过滤和 Sa-Token 鉴权。 |

## core 基础设施文件职责

| 文件 | 处理的问题 |
| --- | --- |
| `app/core/__init__.py` | core 包标识文件。 |
| `app/core/config.py` | Pydantic Settings 配置中心，读取 `.env` 和环境变量，管理数据库、Redis、MinIO、模型、OCR、召回参数等配置。 |
| `app/core/concurrency.py` | 并发控制，限制聊天模型、embedding 和分布式请求槽位，避免模型接口或服务资源被打满。 |
| `app/core/json_utils.py` | JSON 安全转换，把 UUID、datetime、Decimal 等对象转换为可序列化数据。 |
| `app/core/responses.py` | 统一响应结构：`ok()` 和 `error()`。 |
| `app/core/security.py` | 本地 admin 密码 hash、校验和 JWT 生成。Java Sa-Token 校验在 `api/deps.py`。 |

## db 与 schemas 文件职责

| 文件 | 处理的问题 |
| --- | --- |
| `app/db/__init__.py` | db 包标识文件。 |
| `app/db/session.py` | 创建 SQLAlchemy 异步 engine、连接池和 `get_db` 依赖。 |
| `app/db/models.py` | SQLAlchemy ORM 模型，描述 admins、documents、jobs、parse_results、chunks、qa_pairs、conversations、retrieval_logs、feedback、evaluation 等表结构。 |
| `app/schemas/__init__.py` | schemas 包标识文件。 |
| `app/schemas/common.py` | 通用 API 响应模型，便于接口文档和类型约束。 |

## services 服务层文件职责

| 文件 | 处理的问题 |
| --- | --- |
| `app/services/__init__.py` | services 包标识文件。 |
| `app/services/archive_import_service.py` | 压缩包安全解压和过滤，避免目录穿越、超大文件、无效文件进入导入流程。 |
| `app/services/chat_service.py` | 问答主编排：会话、历史、追问改写、检索、模型回答、SSE、引用、推荐问题、日志和撤回。 |
| `app/services/chunk_service.py` | 文档切片逻辑，按配置把解析文本拆成可检索 chunk，并保留页码、章节、表格等 metadata。 |
| `app/services/conversation_title.py` | 会话标题生成、规范化、长度和手动标题校验。 |
| `app/services/document_lifecycle_service.py` | 文档生命周期维护：清理索引内容、清理向量、软删除、知识库版本变更。 |
| `app/services/document_pipeline.py` | 文档处理流水线：从 MinIO 读取文件，解析、保存解析结果、切片、向量化、更新任务进度和文档状态。 |
| `app/services/document_state.py` | 文档状态辅助判断，处理需要转换、需要解压、跳过切片等终态信息。 |
| `app/services/document_upload_service.py` | 普通上传场景的文件名规范化、重名处理、hash、MinIO 写入和文档记录创建。 |
| `app/services/hash_service.py` | 文件和文本 hash 工具，用于去重、内容变更识别和向量缓存。 |
| `app/services/minio_service.py` | MinIO 客户端封装：bucket 初始化、上传、下载、文本写入、代理 URL 生成。 |
| `app/services/model_service.py` | Chat 和 Embedding 模型调用封装，复用 OpenAI-compatible 客户端，处理 embedding 缓存和并发槽位。 |
| `app/services/ocr_service.py` | PaddleOCR 封装，负责图片 OCR、置信度过滤和 OCR 结果结构化。 |
| `app/services/parse_service.py` | 多格式文档解析：PDF、DOCX、DOC、Excel、图片、压缩包；处理 OCR、表格、大表采样、旧 Office 转换。 |
| `app/services/qa_embedding_service.py` | QA Pair 向量同步，保证新增或修改的 QA Pair 能参与语义召回。 |
| `app/services/qa_generation_service.py` | 从文档内容自动生成 QA Pair，用于补充直接问答知识。 |
| `app/services/rag_settings_service.py` | RAG 参数有效值管理，合并默认配置和运行时设置。 |
| `app/services/redis_service.py` | Redis 客户端封装，支持 JSON 缓存、队列 push/pop、分布式并发相关操作。 |
| `app/services/rerank_service.py` | DashScope Rerank 调用封装，对召回候选进行二次排序。 |
| `app/services/retrieval_service.py` | 检索核心：向量召回、关键词召回、QA 召回、RRF 融合、业务过滤、rerank、上下文扩展和引用生成。 |
| `app/services/task_queue_service.py` | Redis 后台任务队列封装，负责入队和阻塞出队。 |

## 代码阅读路线

Java 对接入口：

1. `app/main.py`
2. `app/api/v1/internal.py`
3. `app/api/deps.py`
4. `app/services/document_pipeline.py`
5. `app/services/chat_service.py`
6. `app/services/retrieval_service.py`

文档处理链路：

1. `internal.py` 的 `/documents/process`
2. `task_queue_service.py`
3. `workers/document_worker.py`
4. `document_pipeline.py`
5. `parse_service.py`
6. `chunk_service.py`
7. `model_service.py`
8. `document_lifecycle_service.py`

问答链路：

1. `internal.py` 的 `/chat` 或 `/chat/stream`
2. `deps.py` 做 Sa-Token 鉴权
3. `internal.py` 的 `_allowed_document_ids` 做权限过滤
4. `chat_service.py` 编排会话和回答
5. `retrieval_service.py` 做召回和引用
6. `model_service.py` 调用大模型
7. `retrieval_logs` 记录排查信息
